# FlexHire 🚀

FlexHire is a smart and modern hiring platform that connects job seekers and employers in one seamless experience. It includes user authentication, dashboards, job management, profile updates, and a simple blog section for helpful content.

## ✨ Highlights
- 👤 Role-based login for job seekers and providers
- 💼 Job posting and application flow
- 🧾 Profile management
- 📝 Blog section for updates and tips
- 🌐 Clean and friendly UI

## 🛠 Tech Stack
- React
- Node.js + Express
- PostgreSQL
- JWT Authentication

## ▶️ Run Locally
```bash
npm install-all
npm run backend-dev
npm start
```
